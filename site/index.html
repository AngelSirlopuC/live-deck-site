Your slides, live on every phone in the room.

Live Deck is an open-source player for talks that talk back. You present from a console; the audience follows on their phones, answers quizzes, reacts and chats, without installing anything. Claude writes the deck.

Three steps to a live talk.

  1. 1

    Install the skill

    One command adds the Live Deck authoring skill to Claude.

    npx skills add AngelSirlopuC/live-deck
  2. 2

    Ask for a deck

    Claude picks a theme, writes decks/<id>/deck.json and fixes it until the validator says OK.

    Create a live deck about our Q3 launch
  3. 3

    Go on air

    Set a PIN, open the console and put the join QR on the projector. Phones scan and follow.

    npm run dev:server && npm run dev:web

A slide is a file.

Decks are plain JSON: normalized boxes on a 16:9 canvas, fragments for step-by-step reveals, quiz slides and speaker notes. The schema is strict, so an agent gets exact error paths instead of a broken talk.

Pick a preset and the same slide changes its whole look: colors, fonts, cards and chart palette.

Built for the room, not for the slide editor.

Quizzes
Live bars or secret until you reveal, optional timer and leaderboard. Votes by tap or keyboard (A–F, 1–6). Anonymous attendees get a creative alias.
En vivo / Explorar
The audience follows you in real time, or browses back through the slides already shown and returns with one tap.
Pointer effects
Ripple, focus and zoom, mirrored on the projector and every phone.
Reactions and chat
Floating reactions among the audience; text and GIPHY sticker chat with moderation. You opt in to see either on your screen.
Your own designs
Export slides as images from PowerPoint, Keynote, Google Slides, Canva or Figma. Live Deck adds the join QR, quizzes on your designed options, chat and effects.
Presenter in control
A private console link plus PIN with lockout, a projector screen and a phone remote. Notes and quiz answers never reach the audience before the reveal.
Ephemeral
Sessions live in memory. When you end one, download the summary; then the data is deleted.
Self-hosted
One Docker container behind Caddy. About 200 attendees per session on one small server.

Questions

What is Live Deck?

A view-only presentation player that makes a talk two-way. Slides sync from the presenter to every phone, with quizzes, pointer effects, reactions and chat. Decks are JSON files, usually written by Claude with the bundled skill.

How is it different from poll tools?

Poll tools sit beside your slides in another tab. In Live Deck the slides themselves are the live surface: the deck, the quiz and your pointer gestures reach every phone in real time, and late attendees can browse back on their own.

Does the audience need to install anything?

No. They scan the QR on the first slide and join in the phone's browser, with a first name or anonymously.

Which agents can write decks?

The bundled skill targets Claude. The format is documented and the CLI validates any file, so any agent that can edit files and run a shell can write a deck. See the skill and why there is no MCP server.

Do I have to write JSON by hand?

No. Ask Claude for a deck, or design your slides in any tool, export them as images and run live-deck import.

How many people can join?

About 200 attendees per session on one small server. See self-hosting for sizing.

Is it open source?

Yes, MIT licensed. The code, the skill and these docs live on GitHub.
